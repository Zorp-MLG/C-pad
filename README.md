## ABOUT C-PAD
I tried to come up with a unique idea for stardance, and this is what i came up with. C-pad is able to code with only 9 keys, so you can make simple programs faster! It uses a seeed xiao rp2040 micro controller, 9 Cherry mx style switches, OLED 0.91 screen and 9 diodes.
