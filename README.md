        # Recap 12:ReCap #2. Hello people! The PCB part of the project was quite long, so il do it in a bullet point type of list/story thing. 1. THE START: I started up easyEDA, I wanted to put all the components on the schematic first, but finding all of them were pretty hard, specifically the Cherry MX style keys. I couldnt find them for like an hour😭! I searched up a bunch of different synonyms to it, but kept getting empty handed, Until i found the user contributed tab on easyEDA. I connected them to the microcontroller, But then realized i had to use diodes too. The most difficult part was the different sides, anode and cathode, I kept mixing them up! I added the OLED screen next. The OLED screen was pretty easy to put in, only about an minute or so to put it in the schematic. 2. PCB DESIGN: I started with a few problems, like i didnt know how big the PCB should be and how the layout should look like. I decided it to be 90mm by 86.5 mm. I put the 3x3 switches in a grid, and the microcontroller in the top left corner. The Diodes in the bottom left corner and two screw holes in the corners. 3. THE FINISHED PRODUCT: I at first put a bunch of random silkscreen but then put it all at the back of the PCB and tried to make it more professional in the front. Thats about it! Next ReCap will be at #21 dev log. Thanks for reading! (btw i added net labels in the schematic today.)
